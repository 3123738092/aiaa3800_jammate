# MRT2 中文提示试听

- [「鼓少一点」WAV](01_sparse_prompt.wav)
- [「鼓更密一点」WAV](02_dense_prompt.wav)

两段均由 `mrt2_small` 生成，时长 10 秒，采样率 48 kHz，双声道。将中文原句直接交给 MusicCoCa，两段复用同一组音高条件、鼓活动区间和随机种子。文件名标记文字意图。要判断是否符合意图，可以试听并比较实际发声的鼓点。

[条件记录](conditions.json)包含上一轮网页试听的英文风格和结构化条件，以及中文对照的文件校验值。对照中的中文提示分别替换了原来的英文风格，演奏条件取自同一条记录。
