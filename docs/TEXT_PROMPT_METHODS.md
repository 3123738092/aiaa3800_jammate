# 四种文字提示写法的编排对照

使用两个新题材测试四种写法。每次从相同的 96 BPM、C 大调和默认编制开始，运行一个独立作品。文字由 `gpt-6-luna` 解读，音符由规则编排生成，WAV 由 Kevin / FluidSynth 输出。八种写法均生成了四小节的 MIDI 和 WAV。[完整提示词和验收条件](../examples/text_benchmark/prompt_methods.json) · [逐轮日志](../examples/benchmark_evidence/text_benchmark_20261118/prompt_methods/luna/turns.jsonl)

| 写法 | 午后纸鸢 | 凌晨空站台 |
| --- | --- | --- |
| 情绪短句 | 「轻巧、疏朗、带点俏皮」使鼓、贝斯、键盘的音符总数从 44 降到 33，没有主奏进入。 | 「安静、空旷、慢慢逼近」让全队变轻、音符从 44 降到 33。贝斯各小节平均力度均为 66，未形成渐强。 |
| 纯场景描写 | 写操场、纸鸢和风停时的纸尾。Luna 加了四个主奏音，鼓、贝斯、键盘照旧。 | 写末班车后的灯管、隧道和逐渐靠近的低低震动。Luna 加了三个主奏音，贝斯没有渐强。 |
| 目标加反例 | 指定「小雀跃」，补上「别做成游行」「留空隙给短念头」。Luna 同时稀疏了全队伴奏并加了三个主奏音。 | 说清「悬着的紧张」「低处一点点起来」「别靠加速或重鼓」。只有贝斯渐强，四小节 MIDI 平均力度为 102、109、116、124。 |
| 按声部指挥 | 鼓从 24 个音减到 20，力度控制值保持，贝斯和键盘音符数保持，新增四个主奏音。Luna 把精准控制旋律尾部留白列为未完成项。 | 速度、键盘与主奏保持，鼓变轻。贝斯四小节 MIDI 平均力度为 105、114、123、127。 |

纯场景写法把编排选择交给 Agent。在这两次执行里，它都选了生成短动机，场景中隐含的疏密和张力变化没有同时落地。带反例的写法给出了可执行的变化方向，同时仍允许 Agent 选择具体声部和强弱幅度。按声部指挥可以验收具体输出，也会把执行器缺少的控制暴露出来。

纸鸢最后一条的主奏实际在第 4 拍结束，余下小节没有主奏音。当前的短动机碰巧留出了空间。要精确控制尾部留白，需要在旋律动作里支持短句的落点和结束边界，并通过 MIDI 最后一个音符的结束位置验收。单次对照记录的是各提示写法触发的动作，场景是否贴合可以直接试听。

可以复跑整个对照并导出 WAV 和 MIDI。

```text
python examples/text_benchmark/run.py --cases examples/text_benchmark/prompt_methods.json --model gpt-6-luna --save-audio --fluidsynth "<FluidSynth路径>" --output demo_out/text_benchmark/prompt_methods/new_run
```

逐轮记录可随仓库查看。试听音频可按提示词对照的命令本地重生成。
