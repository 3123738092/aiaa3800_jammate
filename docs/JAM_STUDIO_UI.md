# JamMate 前端

`/jam.html` 打开 Studio v4。`/jam-classic.html` 保留上一版的设备键盘、设置和日志，可从 v4 的设置进入。两套界面共用 JamMate 服务。

v4 的输入栏接收文字、语音、拍手、哼唱与 MIDI。录入的 MIDI 保留演奏起音、力度和时值；文件速度作为素材元数据。运行日志显示实际 InputEvent、BandPlan、排程和播放回执。和声屏只采用已确认会话状态。总音量控制会话混音，设备推子调整本地试听。

打开后或演奏中空闲约 8 秒时可以收到乐队提议。接受开场只开启一小节鼓点或一句旋律。演奏中的接受作为独立的会话操作记录，由后端排到可用小节。设置里可选用已配置的大模型 Agent、音符编排和渲染后端。

运行 `python -m jammate.input_server --port 4193` 启动本机工作台。大模型沿用 [配置说明](LLM_ARRANGEMENT.md)，MRT2 依赖见 [MRT2 后端](MRT2_BACKEND.md)。MRT2 试听生成独立音频，播放试听时暂停内置伴奏。

## 语音指令

工作台有可用听写服务时，打开页面会尝试启动监听。首次使用需授予浏览器麦克风权限。有些浏览器还需一次页面交互才能播放回应，可通过普通页面操作恢复监听。主动关闭麦克风会记住选择，重新点击「说话」即可恢复。可以在一句话里说「Hey JamMate，速度调到 108」，也可以单独说「Hey JamMate」「Hey 节奏组」或「Hey 旋律组」，听到「我在」后继续说指令。停顿后自动转写并提交，处理结果出现在乐队回执和运行日志。叫节奏组或旋律组时，工作台会将对应乐器移到中央。每条指令后可重新唤醒，切出页面暂停监听。

网页用本地停顿检测切分录音，再通过已配置的听写服务识别唤醒词。开启期间，有声音的片段会发送给听写服务。听写可设为讯飞或 Qwen-Audio 优先，另一家配置齐全时自动备用。Qwen 请求附音乐领域词表。已知的转写变体如 `boss and Nova` 会归一为 `Bossa Nova`，原转写仍在 Inspector 可查。[Qwen 上下文增强说明](https://help.aliyun.com/en/model-studio/qwen-audio-asr-http-api)

使用 ChatAnywhere 时，将 Git 忽略的本地配置写为已有 LLM 配置格式，`base_url` 设为 `https://api.chatanywhere.tech/v1`，`api` 设为 `chat_completions`，`model` 填账号已开通的模型。通过 `JAMMATE_LLM_CONFIG` 指向该文件并重启服务。Studio 连接到已配置的模型时，默认用大模型处理指令，可在设置切回本地规则。

## v4 联调

本机 WSL GPU 工作台使用 `127.0.0.1:4196/jam.html`。设置中的「内置伴奏 + MRT2 试听」将当前音符条件交给模型，完成后在下方试听。此次 MIDI 仿真为 6/8、102 BPM，生成 3.53 秒的 48 kHz 立体声。另一轮浏览器导入验收生成并完整播放了 5 秒试听，试听期间暂停了内置伴奏。首次独立推理约 90 秒。

测试使用屏幕琴键、MIDI 文件及合成语音。物理麦克风和 MIDI 键盘尚未联机验收。

## 经典工作台

打开现有服务的 `/jam-classic.html`。最早的设备概念呈现鼓、全乐队和旋律三个可点击对象。点选后文字和语音针对该对象；哼唱、拍手在输入区就地录制与复核。原打击垫和键盘保留于“演奏键盘”。

`jam-studio.js/css` 提供基础设备与试听；`jam-room.js/css` 提供默认界面、情境录入、重组设置和日志面板。所有原有表单 ID 与事件处理保留，旧页面不再作为可见抽屉呈现。字体为本地 Manrope 与系统等线，字体许可证在 `web/fonts`。

`jam.js` 发出 `jammate:audio` 和 `jammate:view` 供波形和播放状态显示，发出 `jammate:submitted` 仅在实际指令提交成功后清空对应草稿。针对选定对象的文字与语音加上未提及的乐器名称，仍由原后端解释，不保证规则解析器理解任意自然语言。

日志分为处理过程、音乐状态、原始数据，读取原调试模块的真实数据。`jam-debug.js` 只调整卷帘配色。`?release=1` 隐藏日志入口，接口权限仍由后端管理。

琴键和鼓垫是本地试听，滑块只影响试听。没有新增真实 MIDI 录入或 3D 渲染后端。麦克风沿用已有录制流程，本轮未做硬件实测。


## 局部渲染 PoC 更新

经典页面采用暗色循环空间浏览。`jam-spatial.js` 与 `jam-spatial.css` / `jam-night.css` 提供循环焦点、对齐读数、真实 select 的可访问视觉代理与渲染验证页。“键盘 / MIDI”在窄屏也可见；连接 MIDI 后仅进行本地 Note-on 短音试听，没有新增后端 MIDI 输入协议。

麦克风 GLB、HDRI 与透明 PNG 均为本地资源。实时模块源码位于 `web/rendering`，构建至 `web/vendor`；默认静态图不加载 Three.js。原业务模块新增只读性能事件，不改变生成与播放。完整实测与构建方式见 `RENDERING_POC.md`。
