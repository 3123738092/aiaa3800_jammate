## 第 3 轮验收

- 「设到 96 BPM，同时让鼓停下来」必须同时改变两个字段，并保持其他声部。
- 「保持速度，让鼓停下来」必须只静音鼓。若同时明确要求保留鼓点，进入等待，不推进小节。
- 显式段长与 BPM 分别核对数值和单位。一个未解析分句、候选漏掉一项、互相矛盾的要求，都需要明确退出或等待。
- 两条路径从相同的初始状态开始。Jev 的退出单独计数。能执行的计划要走实际 BandPlan 校验、渲染与状态提交。

## 完成判据

快路径只执行能够覆盖整条请求且通过校验的计划。出现边界失败时，日志能说明是识别错、参数不一致、状态不匹配，还是退出后完整 Agent 的处理失败。最终报告给出测试覆盖和已观察到的错误，并用独立样本验证本轮接入决定。

最终对照的两条路径都从相同的初始化条件开始。独立会话之间可并发，同一会话按轮次执行，各路径沿用自己的提交状态。耗时从文字请求进入服务计到返回试听或等待，并按直接命中、跳过 Jev 后交给完整 LLM、Jev 候选退回后调用 LLM、由请求校验直接等待分别统计。自动验收要同时检查速度、声部、推进小节、未解决事项以及实际音符，避免只根据分类标签计成功。

## 第 5 轮交付

18 轮由两条路径从相同起始状态执行，完整 Mini 与 Jev 混合路径均提交 13 轮、等待 5 轮。各轮开始前的音乐状态一致，13 对输出的 MIDI 字节相同。另一个人工漏掉声部的 Jev 候选正确触发 Mini 回退，并执行了完整指令。该诊断未计入 18 轮。

| 文字服务请求耗时 | 完整 Mini | Jev 混合路径 |
| --- | ---: | ---: |
| 所有轮次 p50 / p95 | 2.96 / 4.57 秒 | 0.92 / 4.04 秒 |
| 返回试听产物 p50 / p95 | 3.22 / 4.67 秒 | 0.99 / 3.82 秒 |
| 实际 Jev 直达的同 8 轮 p50 | 3.51 秒 | 0.87 秒 |

混合路径的 18 轮中，8 轮由 Jev 选齐候选后执行，6 轮因超出可核对语法直接交给 LLM，4 轮由本地冲突或边界检查直接等待。完整路径调用 Mini 14 次，混合路径调用 Jev 8 次、Mini 6 次。计时涵盖后端文字服务从收件到返回试听或等待，双方使用同一个 NumPy 渲染器。

**接入结论**。将混合路径保留为显式可选的实验入口，限定在可逐项核对的调速、具名声部开关和明确段长。保留本地等待和完整 LLM 回退，网页继续沿用原默认配置。这批数据支持继续试用，覆盖范围内的性能收益是相对于完整 LLM 的。受限语法本身已经能确定答案，实验未测量 Jev 相对于纯本地解析的收益，也未验证更广泛表达的误执行率。释放会话暂停状态的播放指令交给 LLM，此行为在留出实验后有独立回归测试。

## 浏览器 Jam 实验接入

配置 JAMMATE_JEV_API_KEY 或 OHMYGPT_API_KEY 后，「大模型 Agent」先处理能完整解析的指令，再用 Jev 并行判断动作、目标、生效时机、整句覆盖和限制条件。动作与目标的分数门槛为 0.90，代码仍检查原文依据、已有声部、保护条件以及计划是否合法。可直达的新增候选包括单声部音量、密度、开关、明确反拍和具名乐器。风格、选乐器、多步、否定、冲突或证据不足的请求连同分类信号交给完整 Agent，分类失败时也可以回退。

实时入口使用前三个候选小节作为软窗口。能延后的编排按当前会话决策和准备预算计算硬截止，等结果后选安全小节。新指令与停止会使未生效的旧请求失效。「下一小节」在提交时固定目标；其他明确时间位置目前提示用户。MRT2 试听沿用独立的生成路径。

接入复测使用 10 条人工设计请求。2 条由本地解析处理，1 条由真实 Jev 直达，另外 7 条交给完整 Agent，其中 2 次等到了 Jev 的 3 秒超时，4 条预期走完整 Agent 的请求均没有被直达执行。另在浏览器后端验证了 Jev 直接提交反拍调整。该批结果用于检验接线与边界行为，覆盖率仍需以更大的留出样本评估。
